# Sensor Data Analyse Tool

## Beschrijving
Dit programma genereert sensormetingen
en analyseert deze met NumPy.

## Benodigdheden
- Python
- NumPy
- Matplotlib

## Installatie
Installeer de benodigde modules:

pip install numpy matplotlib

## Gebruik
Start het programma met:

python main.py

## Functionaliteiten
- Genereren van sensormetingen
- Berekenen van gemiddelde en standaardafwijking
- Detecteren van uitschieters
- Visualiseren van meetgegevens
- Opslaan van gegevens in CSV
